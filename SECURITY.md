# Security Policy

This is the default security policy for `exploopio` repositories that do not have their own.

**Do not open a public GitHub issue, pull request or discussion for a vulnerability.** Report it privately:

- email **security@openctem.io**; or
- GitHub private vulnerability reporting: **Security → Report a vulnerability** on the affected public repository.

Include the affected service, repository or version, the impact, reproduction steps or a proof of concept, and how you would like to be credited.

Test only against systems you own or are authorised to test. The disclosure policy is the [OpenCTEM security policy](https://github.com/openctemio/openctem/security/policy).
