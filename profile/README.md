**Exploop** is continuous threat exposure management as a service. It runs the CTEM loop end to end: scope what matters, discover your external and internal attack surface, prioritise by real exploitability, validate with retests and pentests, and mobilise the fix until it is verified closed.

Exploop runs the same signed images as the open-source [OpenCTEM](https://github.com/openctemio) platform, operated for you, with managed scanning, single sign-on and enterprise add-ons.


### The loop

| Scope | Discover | Prioritise | Validate | Mobilise |
|---|---|---|---|---|
| Assets, owners and rules of engagement | EASM, cloud, code and network inventory | KEV, EPSS, reachability, attack paths | Retests, pentest campaigns, evidence | Grouped fixes, two-way tickets, verified close |

### Open source

The platform is open source and self-hostable. Start at [openctemio/openctem](https://github.com/openctemio/openctem); docs at [docs.openctem.io](https://docs.openctem.io).

### Security

Report a vulnerability through the [OpenCTEM security policy](https://github.com/openctemio/openctem/security/policy). Please do not open public issues for security reports.
